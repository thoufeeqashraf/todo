# Project Brief

## Product Name
ToDo App

## Vision
Multi-tenant task management platform designed for businesses across multiple industries.

## Target Industries (v1)
1. Restaurant
2. Retail
3. Property Management
4. Construction
5. Hospitality
6. Healthcare
7. Logistics
8. Manufacturing
9. Education
10. Security
11. Cleaning & Facilities
12. Agriculture
13. Events

## Core Value Propositions
- **Multi-tenant architecture** with complete data isolation
- **Industry-specific defaults** for quick onboarding
- **Modular feature system** - enable only what you need
- **Flexible deployment** - South Africa, EU, or multi-region

## User Types
- **Company Admin**: Created during signup, full access to company settings
- **Operators**: Development/admin users (tenant-agnostic)
- **Staff Users**: (Future) Regular employees

## Data Residency
Flexible configuration supporting:
- South Africa (za)
- European Union (eu)
- Multi-region deployments
